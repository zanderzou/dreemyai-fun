# Dreemy AI Guide

Independent Astro + Markdown publication for `dreemyai.fun`, focused on Dreemy AI character roleplay, bot creation, image and video tools, safety, privacy, comparisons, and alternatives.

## Commands

```bash
npm run dev
npm run build
npm run preview
npm run test:seo
npm run test:sites
```

Add articles under `src/content/blog`. Astro generates article routes, the blog index, structured data, XML sitemap, and RSS feed.

Cloudflare Pages settings:

- Production branch: `main`
- Build command: `npm run build`
- Output directory: `dist/client`
